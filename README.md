## Required quiz layout

Each assigned quiz will use its own folder:

```text
quiz-01/
    solution.py
    test_solution.py
    README.md
```

Each quiz README will explain the task, how to run the solution and tests, and show sample output.

## Working process

Commit meaningful progress as it happens, with a message explaining the change.
Push at the end of each work session and before the quiz deadline.

Run a quiz's tests from inside its folder:

```sh
python3 -m pytest test_solution.py -v
```
